## Projects

### 1. Hangman Word Guessing Game

Hangman is a word-guessing game developed using Python.

In this game, the computer randomly selects a word from an external text file, and the player has to guess the word one letter at a time.

For every incorrect guess, a part of the hangman is displayed. The player must guess the complete word before the hangman drawing is finished.

**Features:**
- Random word selection.
- Loads words from an external text file.
- Displays hidden letters using underscores.
- ASCII Hangman drawing.
- Tracks remaining attempts.
- Prevents repeated guesses.
- Validates user input.
- Displays winning and losing messages.

### 2. Rule-Based Interactive Chatbot

This is a simple terminal-based chatbot developed using Python.

The chatbot interacts with users by recognizing greetings and answering frequently asked questions.

It loads predefined greetings, questions, and answers from an external JSON file. When a user enters a question, the chatbot checks for a matching response. If no match is found, it displays a default message.

**Features:**
- Interactive terminal conversation.
- Recognizes common greetings.
- Answers frequently asked questions.
- Loads data from a JSON file.
- Handles unknown questions.
- Supports continuous conversation.
- Allows users to exit the chatbot.

## How to Run

1. Install Python on your computer.
2. Clone or download this repository.
3. Open the project in PyCharm or another Python IDE.
4. Navigate to the project folder you want to run.
5. Run hangman.py to play the Hangman game.
6. Run chatbot.py to interact with the chatbot.

Make sure the required text and JSON files are present in their respective folders.
